# Melvor Idle 2 非公式日本語化パッチ

Melvor Idle 2を日本語でプレイするための非公式日本語化パッチです。

## この日本語化パッチについて

本パッチは、以前Steamのレビューで日本語化ファイルを公開されていた方の翻訳データを元に、修正・改善を加えたものです。

私がゼロから作成したものではありません。

元の翻訳ファイルを作成し、導入方法や翻訳に関する情報を公開してくださった方に、この場を借りて感謝申し上げます。

今回、AIを活用して戦闘画面の表示不具合や、一部アイテム名が翻訳されない問題などを修正しました。

まだ未翻訳の箇所や不自然な日本語が残っていますが、ある程度日本語でプレイできる状態になったため、共有することにしました。

## 対応バージョン

Melvor Idle 2 v0.11.6-alpha.1

## ダウンロード

GitHubの「Releases」から、以下の日本語化パッチをダウンロードしてください。

**Melvor-Idle-2-Japanese.zip**

※「Source code (zip)」ではなく、上記のZIPファイルをダウンロードしてください。

## 導入方法

### ① ZIPファイルを解凍する

ダウンロードしたZIPファイルを右クリックし、「すべて展開」を選択してください。

解凍すると、次の構成になっています。

```text
📁 Melvor-Idle-2-Japanese
├── override.cfg
└── 📁 Locale
    └── ja.po
```

### ② ゲームのインストールフォルダを開く

1. Steamを起動します。
2. 「ライブラリ」から「Melvor Idle 2」を探します。
3. ゲームを右クリックし、「管理」→「ローカルファイルを閲覧」を選択します。

※Steamのバージョンによっては「プロパティ」→「インストール済みファイル」→「参照」から開きます。

インストール先の一例：

```text
C:\Program Files (x86)\Steam\steamapps\common\Melvor Idle 2
```

※インストール先は環境によって異なります。

### ③ 日本語化ファイルをコピーする

解凍した以下の2つを、ゲームのインストールフォルダにコピーしてください。

- `override.cfg`
- `Locale` フォルダ（中に `ja.po` が入っています）

```text
📁 Melvor Idle 2
├── override.cfg
└── 📁 Locale
    └── ja.po
```

すでに同名のファイルが存在する場合は、上書き前にバックアップを取ってください。

### ④ ゲーム内で日本語を選択する

1. Melvor Idle 2を起動します。
2. ゲーム内の「Settings」を開きます。
3. 「Language」の項目を探します。
4. 言語一覧から「Japanese」を選択してください。

これで日本語表示に切り替わります。

※一部の項目は英語のまま表示される場合があります。

## 日本語化を解除して元に戻す方法

日本語化パッチを使用しなくなった場合は、次の手順で元の状態に戻せます。

### ① ゲームを終了する

Melvor Idle 2を完全に終了してください。

### ② 追加したファイルを削除する

Steamからゲームのインストールフォルダを開き、今回の日本語化パッチで追加した以下のファイルを削除してください。

- `override.cfg`
- `Locale` フォルダ内の `ja.po`

※ `Locale` フォルダ内にほかのファイルが存在する場合は、フォルダごと削除しないでください。

※導入前から存在していたファイルを上書きした場合は、削除するのではなく、バックアップから元のファイルを復元してください。

### ③ ゲームを起動する

再びSteamからMelvor Idle 2を起動してください。

日本語化パッチが読み込まれなくなり、元の言語環境に戻ります。

必要に応じて、ゲーム内の「Settings」→「Language」から使用する言語を選択してください。
