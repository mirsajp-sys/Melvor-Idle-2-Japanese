# Melvor Idle 2 非公式日本語化パッチ

Melvor Idle 2を日本語でプレイするための非公式日本語化パッチです。

## 対応バージョン

Melvor Idle 2 v0.11.6-alpha.1

## ダウンロード

GitHubの「Releases」から最新版の日本語化パッチ（ZIPファイル）をダウンロードしてください。

## 導入方法

1. ダウンロードしたZIPファイルを右クリックし、「すべて展開」を選択して解凍してください。
2. 解凍すると、次のファイルとフォルダが現れます。

   ```
   override.cfg
   Locale/
       ja.po
   ```

3. Melvor Idle 2のゲームフォルダを開いてください。
4. `override.cfg` と `Locale` フォルダを、フォルダ構成を維持したままゲームの指定場所へコピーしてください。
5. すでに同名のファイルが存在する場合は、上書きする前に必ずバックアップを取ってください。
6. ゲームを起動し、日本語で表示されることを確認してください。

※導入先の正確な場所はゲームのインストール環境によって異なります。

## 現在の翻訳状況

- Bankのアイテム名を日本語化
- 戦闘画面の一部を日本語化
- 各種メニューや説明文を日本語化
- 一部に英語表記が残っています

現在も翻訳の修正・改善を進めています。

## 注意事項

- 本パッチは非公式の日本語化データです。
- ゲーム開発元とは関係ありません。
- ゲームのアップデートによって正常に動作しなくなる可能性があります。
- 導入は自己責任でお願いいたします。
